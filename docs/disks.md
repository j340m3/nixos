# Disks

Disk/USB serials, UUIDs, and labels live in each host's `hardware-configuration.nix`
(or `disk-config.nix` for disko hosts). This page summarizes the *layout* so a
reinstall or rescue is easier. Always treat those source files as authoritative.

## Graphical

### lenny (ThinkPad X230)

- `/` ext4, `/boot` ext4 (separate partition).
- `swapDevices = []`; swap comes from `/swapfile` (2 GiB, defined in `default.nix`) plus zram.
- BIOS/legacy GRUB on `/dev/sda` (`useOSProber = true`).

### rex (work laptop VM)

- `/` ext4, `/boot` vfat (EFI).
- No swap devices; zram.
- systemd-boot.

### sid (WSL)

- No physical disks; NixOS-WSL on the Windows filesystem. No hardware-configuration.

### slinky (uConsole / Raspberry Pi 4)

- `/` ext4, `/boot/firmware` vfat.
- No swap devices; zram. extlinux bootloader.
- Note: aarch64 — cannot be evaluated/built from an x86_64 host.

### woody (homeserver)

- `/` ext4, `/boot` vfat (EFI).
- Swap: see `swapDevices` in `hardware-configuration.nix` (currently `mkForce` list).

### zurg (ThinkPad P51)

- btrfs on LUKS: `/`, `/home`, `/nix` are subvolumes of the same btrfs pool
  (`/dev/disk/by-label/root`), unlocked via `boot.initrd.luks.devices."cryptroot"`
  on `/dev/md0` (mirrored).
- `/boot` and `/boot-fallback` vfat (mirroredBoots).
- Swap: multiple partitions (`swapDevices`).
- GRUB with `configurationLimit = 5`.

## Headless

### bootstrap / bootstrap-impermanent

- Disko image: GPT on `/dev/vda`, 1 MiB EF02 (GRUB) + 512 MiB EF00 ESP (`/boot`,
  vfat) + rest btrfs root (`compress=lzo`).
- `swapDevices` = `/swapfile` (1 GiB); zram; `services.btrfs.autoScrub`; beesd.
- Built as `packages.x86_64-linux.image[-impermanent]` (disko QEMU VM).
- `bootstrap-impermanent` additionally uses `modules/persistence.nix`
  (impermanent root).

### buzz (VPS, Ionos)

- No `hardware-configuration.nix`; GRUB config in `default.nix`. VPS root disk.

### jessie

- `/` btrfs (`/dev/vda3`), `/nix` same btrfs pool, `/boot` vfat (`/dev/vda2`).
- Swap = `/nix/persist/swapfile` (persistent swap).
- GRUB.

### mrpotatohead (VPS)

- Disko: GPT on `/dev/vda`, 1 MiB EF02 + 500 MiB ESP (`/boot`, vfat) + LVM PV.
- LVM VG `pool` → LV `root`, btrfs (`compress-force=zstd`, `nosuid`, `nodev`) at `/`.
- Defined in `disk-config.nix`.

### pricklepants (VPS, Ionos)

- `/` ext4 (`/dev/vda1`); GRUB on `/dev/vda`.
- Swap = `/dev/vda16`.
- nebula lighthouse; also a remote builder.

## Notes

- `hardware-configuration.nix` is generated by `nixos-generate-config` and should
  not be hand-edited (except where already customized).
- Prefer `/dev/disk/by-uuid/...` or `by-label/...` over `/dev/sdX`/`/dev/vdX` in
  filesystem definitions to survive device renumbering.
- For encrypted hosts, the LUKS keyfile/password path is host-specific (see sops
  / initrd config); not documented here.
